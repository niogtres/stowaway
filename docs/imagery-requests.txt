DOCKERBACKUP: IMAGERY REQUESTS
================================
Drop finished files into:  assets/brand/   (create it; keep the file names below)
Claude converts formats (ICO, BMP, favicon sizes) from your masters, so you only need to supply the PNG/SVG masters.

GLOBAL ART DIRECTION (applies to every image)
- Mood: "calm confidence": a premium, modern infrastructure tool. Think Linear / Vercel / Raycast polish, not cartoonish.
- Palette (dark UI is primary):
    background navy-ink   #0F1420   (surfaces slightly lighter: #1A2030)
    accent gradient       #5EEAD4 (teal) -> #38BDF8 (sky blue), left-top to right-bottom
    secondary glow        #8B7CF6 (soft violet), used sparingly as ambient light only
    status                green #34D399 · amber #FBBF24 · rose #FB7185
    neutral line/stroke   white at 8-12% opacity
- Style: flat geometric shapes with soft gradients and subtle inner glow; clean vector edges; no photorealism, no 3D clay, no glossy skeuomorphism.
- NO TEXT in any image (we render text in the UI).
- DO NOT use the Docker whale, Docker logo, Moby, shipping-container photos, or anything resembling Docker Inc. branding (trademark).
  Abstract stacked "layers/blocks" and shields are fine.
- Transparent backgrounds unless stated otherwise.
