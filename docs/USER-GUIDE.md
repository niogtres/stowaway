# Stowaway user guide

*Sensible Docker backup management.*

Stowaway backs up the containers, compose stacks, volumes and bind mounts on a Windows 10/11 computer running Docker, on a schedule, and restores them when you need to. It runs as a Windows service and you manage it from a web page at **https://localhost:8484**.

This guide covers installing it, making your first backup, restoring, and keeping an eye on things.
