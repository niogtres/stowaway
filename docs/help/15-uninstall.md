# Uninstall

Uninstall **Stowaway** from *Settings → Apps* in Windows. This removes the service, the tray icon, the firewall rule and the certificate it trusted.

It **keeps** `C:\ProgramData\Stowaway`, which holds the keys to your backups. Your backups at the destinations are never deleted. If you won't need those backups any more, and you've saved the recovery keys you want to keep, you can delete that folder yourself.
