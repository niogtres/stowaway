# The tray icon

The Stowaway icon in the notification area shows the protection status at a glance (for example *100% protected* or *2 backups failing*) and pops up a notice when backups start failing. Right-click it to open Stowaway, **Activity** or **Snapshots**. Double-click opens the dashboard.

**See also:** [Watching backups run](06-activity.md), [Notifications](10-notifications.md)
